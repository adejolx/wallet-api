# Wallet API apprenticeship

This repository is a learning project for building a small fintech backend with
TypeScript and Express. Day 1 established the application shell: configuration,
a health endpoint, structured errors, and request-level tests.

## Current exercise

Continue with [Day 2: model the wallet domain](docs/day-02-wallet-domain.md).
